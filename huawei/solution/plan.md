# D 题工作方案

## 用户偏好与交付

- 赛题：2026 年中国研究生数学建模竞赛 D 题，共四问。
- 论文：中文；使用已安装的 Typst 与华为杯模板结构，输出匿名 PDF 工作稿。正式上传文件名需要真实队伍编号。
- 输入：`../huawei/` 下的官方题面、五个基础工作簿、DEM 与提交模板；原件只读。
- 计算基线：用户指定的 `../huawei/26华为杯D题/26研赛全套成品D题+解析思路+word版本+推荐高质量版本/代码3.0/`。
- 输出：本目录内的报告、论文源文件、PDF、隔离运行结果和核验记录。

## 工作流

| 阶段 | Skill | 主要产物 | 验收重点 |
| --- | --- | --- | --- |
| 1. 赛题分析与建模 | `2analysis-modeling` | `reports/ANALYSIS_MODELING_REPORT.md` | 四问约束、统一物理口径、歧义预检 |
| 2. 代码与数据图 | `3coding-visual` | `runs/reproduced/`、`reports/RESULTS_REPORT.md` | 重跑、逐箱与资源校验、图表数据来源 |
| 3. 非数据图 | `4drawio` | 必要时 `figures/*.drawio` 与 PDF | 仅在论文确实需要时绘制 |
| 4. 论文 | `5writing` | `paper/main.typ`、`paper/*.typ`、PDF | 华为杯格式、真实结果、图文对应 |
| 5. 验收 | `6verity` | `reports/VERIFY_REPORT.md` | 交叉核对、编译、逐页视觉检查 |

## 求解路线

1. 用同一 DEM 航段与能耗规则计算单点安全载荷，以精确集合划分求 Q1 组批。
2. Q2 保持硬时限与资源约束，采用可行解优先的路线搜索和时序解码；启发式结果不宣称全局最优。
3. Q3 在运输方案上联合调整路线、时刻与中继架次；使用双向链路和 1 秒采样网格验证覆盖，并明确采样验证不能等同连续时间解析证明。
4. Q4 对 Q3 路线形成的不可拆任务块枚举 2 组与 3 组分区，按缺口、冗余、均衡程度排序。

## 风险控制

- 旧代码运行日志使用 `D:\huawei`，必须以本机隔离重跑结果为准。
- 旧总论文有插图占位和数学符号转换错误，仅供逐项比对。
- 官方 AI 使用规定要求参赛队理解、核实、用自身语言表述并披露辅助使用；在附录与程序说明中留存记录。
- 公开 GitHub 仅提交经核验的代码、必要数据和最终结果，不提交重复缓存与多份冲突稿。
